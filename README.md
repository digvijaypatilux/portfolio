# Digvijay Patil — UI/UX Designer Portfolio

A single-page portfolio built with plain HTML, CSS and JavaScript. No build step and no dependencies.

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000

## Structure

```
index.html          page markup, styles and scripts
assets/portrait.webp  hero portrait (transparent background)
assets/me.webp        About section photo
```

## Deploy with GitHub Pages

Repo Settings → Pages → Deploy from a branch → `main` / root.
